Mizan is a community project for Lunch Money users who want less guesswork in their zakat calculation.

Lunch Money already had my balances.

Most calculators ask you to type in what you own and what you owe. I wanted to start with my Lunch Money balances instead of guessing the totals.

So I built Mizan. It reads those balances and lets you check what belongs in the calculation. You can edit an amount or add anything Lunch Money doesn't have, such as cash at home. It can't check your coat pockets, so that bit is still on you.

You can check how the total adds up.

Open the breakdown to see each account and deduction. Mizan labels amounts you change here, so you can tell which numbers came from Lunch Money. Anything you add is listed there too.

The graphs use the same amounts as the calculation. You can also compare methods or look through the monthly balances Lunch Money has available.

A few choices are still yours.

Choose the zakat method you follow and check any balance marked "not current". You will also need to add assets that are missing from Lunch Money. Mizan shows the gaps so you can check them before using the estimate.

This started with my own calculation. It is now a community project for other Lunch Money users who want to use the balances they already track.

You can explore more tools on Lunch Money's developer page, or read the official API documentation to see what the integration is built on.
