Getting connected

Get your Lunch Money
access token.

An access token is a private code that lets Mizan read your budget. You create it in Lunch Money, then paste it into the calculator.

Use a separate token and keep it private. Lunch Money tokens can read and change data; Mizan only uses read requests.

  1. Open the Developers page

    Sign in to Lunch Money in a new tab. Go to Settings → Developers, or use the direct link below.

    Open Lunch Money Developers ↗

    If you have more than one budget, check that you're using the budget you want to calculate.

  2. Request a new token

    Choose Request New Access Token. If you're asked for a name, use Mizan so you can recognize it later.

    Settings → Developers → Request New Access Token

  3. Copy it, then return to Mizan

    Copy the entire token when Lunch Money shows it. You only see the full token once. Return to the calculator, paste it into Lunch Money access token, and choose Connect my accounts.

    Return to the calculator →

    Paste only the token itself. You don't need to add “Bearer”, quotation marks, or your Lunch Money password.

  4. Remove the token when you're done

    For a temporary connection, use a separate token for Mizan. After your calculation, return to the Developers page and delete that token. You'll make a new one next time.

If you get stuck

I can't find my token

An existing token may be hidden after you create it. Request a new one on the Developers page, and copy it while it's shown.

Mizan says the token doesn't work

Copy the full token again, without extra spaces or quotation marks. If it was deleted or belongs to a different setup, request a new one. Mizan clears the input each time you try to connect.

Can I try Mizan without a token?

Yes. On the calculator, choose Explore with sample data. Sample mode shows the same flow using fictional accounts.

Token steps follow Lunch Money's setup instructions and API authentication documentation.
